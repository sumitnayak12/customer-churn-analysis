# Customer Churn Analysis

## Project Overview

This project analyzes customer churn data to identify patterns and factors associated with customer attrition. The analysis uses data cleaning, exploratory data analysis, statistical analysis, and data visualization to understand customer behavior and churn trends.

## Objectives

- Analyze customer churn patterns.
- Identify key factors associated with customer churn.
- Compare churn across different customer segments.
- Explore the relationship between customer characteristics and churn.
- Generate insights that can help improve customer retention.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Spyder
- SQL

## Analysis Performed

The project includes:

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Categorical and numerical variable analysis
5. Churn rate analysis
6. Customer segmentation
7. Data visualization
8. Identification of major churn-related factors

## Key Findings

The analysis identified several customer characteristics and service-related factors associated with higher churn rates.

Key findings from the analysis include:

- Month-to-month customers show a higher churn rate.
- Customers with shorter tenure are more likely to churn.
- Electronic check payment users show a relatively higher churn rate.
- Fiber optic customers show a comparatively higher churn rate.
- Customers with certain service combinations have different churn patterns.
